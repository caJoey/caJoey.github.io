# Joey Capps Portfolio

A modern responsive personal portfolio site for Joey Capps, built with React,
Vite, and TailwindCSS.

<img width="551" height="548" alt="Screenshot 2026-10-13 at 3 38 01 PM" src="https://github.com/user-attachments/assets/30ea6a15-a192-466d-9ee1-a57eacd06791" />

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The site is available at:
